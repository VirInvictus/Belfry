# Belfry — Keyboard Shortcuts

Reference for the keyboard map. Wired as the UI lands; the targets below come from `spec.md` §3 and the v0.5 distribution checklist.

## Playback

| Action | Shortcut |
|---|---|
| Play / pause | Space |
| Skip back | ← / J |
| Skip forward | → / L |
| Mark played | K |
| Decrease speed | , |
| Increase speed | . |
| Sleep timer | S |
| Toggle Smart Speed | (TBD) |
| Toggle Voice Boost | (TBD) |

## Triage

| Action | Shortcut |
|---|---|
| Add to queue | Q |
| Star / save | F |
| Mark archived | A |

## App

| Action | Shortcut |
|---|---|
| Search | Ctrl+F |
| Add feed | Ctrl+N |
| Toggle sidebar | F9 |
| Quit | Ctrl+Q |

(Filled in incrementally as the UI ships. Any new shortcut must have a visible UI control too — see Framework's discipline in `CLAUDE.md`.)
